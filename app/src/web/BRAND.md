# Brand assets

The **official BMO Capital Markets mark**, supplied by the demo owner and used
**for demo presentation only**. `_source-bmo.png` is that artwork; every file
below is derived from it by `make_brand.py` — cropped, background-removed and
rescaled. Nothing is redrawn or restyled.

All internal data in this application is synthetic and generated by
`capital-markets-client-intelligence/data/`; nothing here originates from BMO.

Gibson Energy Inc. (TSX:GEI), Keyera Corp., Whitecap Resources Inc. and the
other TSX-listed issuers in this demo are real public companies, named only so
that live Web IQ grounding returns genuine public news. Every internal figure —
exposures, limits, covenants, revenue, ratings, policies, emails — is invented.

| File | Use |
|---|---|
| `_source-bmo.png` | the supplied official lockup — the only hand-placed asset |
| `cm-lockup.png` | full lockup, trimmed — the sign-in card |
| `cm-logo.png` | 512px red roundel, transparent corners — general use |
| `cm-logo-white.png` | 512px mono white — the blue top bar |
| `favicon.png` | 64px roundel — browser tab |

**Why the roundel and not the lockup in the top bar.** At 26px the wordmark is
unreadable, and the bar already spells the name out beside it. The sign-in card
has room, so it gets the full lockup.

**Why the roundel is masked, not background-removed.** The mountain device inside
the circle is *white*. Dropping white pixels — which is how the previous
generated mark was built — punches a hole straight through the glyph. It looks
correct on a white page and wrong the moment it sits on the blue top bar. The
roundel is therefore masked to its circle, which removes only the corners.

The white variant forces RGB to white and preserves alpha, so the mark keeps its
internal structure against the blue bar rather than flattening into a disc.

## Palette

Sampled directly from the supplied artwork and set in `src/styles.css` `:root`.

| Token | Value | Use |
|---|---|---|
| `--brand` | `#0079c2` | BMO blue — top bar, primary actions, active states |
| `--brand-deep` | `#005a94` | hover, links, headings on tint |
| `--brand-tint` | `#e5f1fa` | the "what actually binds" reveal column, callouts |
| `--accent` | `#ed1c24` | BMO red — warnings, note rules, sparing emphasis |

IQ layer colours are deliberately unchanged across every demo in this repo, so
the four layers read the same way wherever they appear: Work `#7c3aed`, Fabric
`#0f766e`, Foundry `#b45309`, Web `#1d4ed8`.

## Regenerating

```powershell
pip install pillow
python make_brand.py                # uses _source-bmo.png
python make_brand.py other-mark.png # or point it at a replacement
```

The roundel is located by **colour**, not a hardcoded crop box, so re-supplying a
differently-proportioned source still works.
